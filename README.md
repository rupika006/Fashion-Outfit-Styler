## 🌸 About the Project

FashionSense AI is an AI-powered fashion recommendation system that generates coordinated outfits based on users' budgets, preferred clothing types, colours, and fashion aesthetics.

It combines Machine Learning and Deep Learning to recommend complete outfits using real fashion product images.

## ✨ Features

- Personalized outfit recommendations.
- Budget-based outfit generation.
- Multiple clothing category selection.
- Colour coordination and aesthetic matching.
- CNN-based image classification.
- Logistic Regression-based text classification.
- Outfit compatibility scoring.
- Multiple outfit suggestions.

## 🧠 Machine Learning Models

**1. Logistic Regression**
Uses TF-IDF text features to classify products according to fashion aesthetics.

**2. Convolutional Neural Network (CNN)**
Analyzes product images, predicts aesthetics, and generates visual embeddings to help identify visually compatible clothing combinations.

## 📊 Dataset

**Women's Fashion Catalogue – Hugging Face**

Dataset: `arturayupov/womens-fashion-catalog`

Contains fashion product information and images used for outfit recommendations.

## ⚙️ How to Run

1. Open the project notebook in Google Colab.
2. Run all cells in sequence.
3. Allow the dataset and product images to load.
4. Select your budget, clothing categories, colours, and aesthetic.
5. Click **Generate My Outfit**.
6. Explore your personalized outfit recommendations.

## 🎯 Objective

To simplify fashion discovery by combining artificial intelligence, image classification, and personalized recommendation techniques to generate complete, coordinated outfits.
